# Cancellations

Maple Market cancels **whole orders**, not individual line items. If you only want to drop
one product, cancel the order (when allowed) and place a new one.

## When cancellation is allowed

You can cancel an order only while its status is **placed** or **processing**.

| Status        | Can cancel? | What to do instead                          |
| ------------- | ----------- | ------------------------------------------- |
| placed        | Yes         | Ask support; the system will cancel it      |
| processing    | Yes         | Same as placed                              |
| shipped       | No          | Wait for delivery, then use the returns policy |
| delivered     | No          | Use the returns policy                      |
| cancelled     | No          | Already cancelled                           |

Once an order is **shipped** or **delivered**, it cannot be cancelled.

## How to cancel

Cancellation is performed in our system. A chat message alone does not cancel an order.
Support will confirm the order id and status first, then run the cancellation.

Only the customer who placed the order can cancel it. We will not cancel someone else's order.

## After a successful cancel

- Status becomes **cancelled**.
- If payment was captured, a full refund goes to the **original payment method** within
  **1–2 business days**.
- We do not issue store credit for cancellations.

## What we will not do

- Partial cancels (remove one SKU, keep the rest).
- Address or item swaps on a cancelled order — place a new order instead.
- Cancelling after the carrier has the parcel. That is a return, not a cancel.
