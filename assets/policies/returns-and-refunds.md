# Returns and refunds

## Return window

You may return an unused item within **14 days of delivery**. The clock starts on the
**delivered** date, not the order date and not the ship date.

After 14 days we do not accept returns except for a manufacturing defect or a food-safety issue.

## Condition of the item

The item must be **unopened**, in original packaging, with tags attached (where the product
had tags). We inspect returns before refunding.

Opened or used items cannot be refunded except for a **manufacturing defect**.

### Category notes

- **Kitchen appliances** (blender, coffee maker): unused, unplugged, all parts in the box.
  A jug that has been washed or a machine that has been powered on counts as used.
- **Textiles** (tote, apron): unused, tags on, no stains or odour.
- **Candles**: wick unburned, wrapper intact.
- **Pantry** (maple syrup, tea): sealed and unopened only. An opened food jar or pouch
  cannot be returned unless there is a safety or manufacturing defect.

## Defects and wrong items

- **Manufacturing defect** (cracked jug, dead blender, leaking bottle): return even if opened.
  Photograph the issue if you can; we still need the item back.
- **Wrong item or missing item**: contact support with the order id. We replace or refund;
  you should not have to pay return postage for our mistake.
- **Damaged in transit**: same as a defect. Keep the outer carton if it shows carrier damage.

## How a return works

1. Contact support with the order id and which items you want to send back.
2. We confirm the window and condition. We cannot start a return on an order that is still
   **placed**, **processing**, or **shipped** — wait until it is **delivered**.
3. Pack the item and send it to the address we give you. Standard returns: **customer pays
   postage** unless the return is our error or a defect.
4. Refunds are issued to the **original payment method** within **5–10 business days** after
   we receive the return.

We do **not** offer store credit in this version of the shop.
We do **not** offer like-for-like exchanges. Return the item, then place a new order if you
want a replacement that is not a defect/wrong-item case.

## Partial returns

You may return some lines of an order and keep others. Each returned line must still meet
the 14-day window and condition rules. The refund is only for the returned items, not the
whole order.
